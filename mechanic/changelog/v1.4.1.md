# v1.4.1

## **Features**

* Manual transmission (installable via the tablet) - [Docs](https://docs.jgscripts.com/mechanic/manual-transmissions-and-smooth-first-gear)
* Global 'smooth first gear' option

## **Fixes**

* Fix issue where addon wheels would sometimes reset in the tuning menu
* Fix error regarding missing `commission` in the config
* Fix UI layout bugs in tuning
* Shops & stashes code is no longer encrypted

## **Integrations**

* Added codem-inventory & expanded support for qs-inventory

## **Config**

* 2 new config options, `Config.SmoothFirstGear`, `Config.ManualHighRPMNotifications`
* New gearbox tuning option has to be added to location(s) -> `MechanicLocations->[name]->tuning->gearboxes`
* New `gearboxes` tuning config in `config.tuning.lua`

## **Locales**

* New locales added, please replace with new files in `locales` folder
